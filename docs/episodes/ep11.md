## Episode Outline

### Skills vs MCP Tools — What's the Difference? (~3 min)
The distinction is important and worth spending a minute on:

**MCP tools** are capabilities — they give Claude access to data. `query_sql`, `get_options_chain`, `get_ohlcv` are tools. They do things.

**Skills** are instructions — they teach Claude how to use those capabilities well for a specific task. A skill is a markdown file that says: "when asked about market data, here's how to think about it, what tools to call, in what order, and how to format the response."

Without a skill, Claude will often figure out the right tool calls on its own — but it might use a suboptimal approach, return data in an inconsistent format, or make extra unnecessary tool calls. A skill locks in the right behavior.

Think of it this way: MCP tools give Claude hands; skills teach Claude what to do with them.

### The query-market Skill — What It Contains (~2 min)
Walk through `skills/query-market.md` on screen. The skill defines:
- What this command is for (market data queries)
- The available MCP tools and when to use each
- How to interpret common query types (screener, options chain, Greeks, vol surface)
- Response format instructions (tables, not paragraphs, for tabular data)
- Error handling guidance (what to say if data is missing or the query fails)

### Installing the Skill (~1 min)
Claude Code skills live in the `.claude/` directory of your project (or globally in `~/.claude/`). The skill is already in `skills/query-market.md`. To make it available:

```bash
# Skills in the project root are auto-discovered by Claude Code
# The file at skills/query-market.md is already included in the repo
# Verify it's registered:
ls skills/
# query-market.md

# In Claude Code, run:
# /help
# You should see /query-market listed under available skills
```

### Live Demo (~4 min)

## Key Concepts

**Skills — executable markdown**
A Claude Code skill is a markdown file that Claude loads as system context when you invoke the slash command. It's not code — it's instructions. But those instructions guide Claude to write better code, call tools in better order, and format responses more consistently. Skills are the fastest way to encode institutional knowledge about how to use a tool.

**Skills as reusable prompt templates**
Every time you invoke `/query-market`, Claude re-reads the skill file. The skill acts as a standing system prompt for that specific task. This means you can iterate on skill behavior by editing the markdown — no code changes required. If Claude keeps formatting vol surfaces the wrong way, update the formatting instructions in the skill and it's fixed for all future invocations.

**When to use /query-market vs just asking**
Use `/query-market` when:
- You want consistent, structured output (tables, not paragraphs)
- You're running a specific type of query you'll run repeatedly
- You want Claude to use the MCP tools proactively rather than waiting for explicit instruction

Just ask Claude normally when:
- You're exploring, not yet sure what query you want
- You want Claude to reason about market concepts, not just pull data
- You're not connected to the MCP server

**Extending the skill**
Skills are easy to extend. Open `skills/query-market.md` and add a new section for a new query type you want to support. For example, you could add instructions for how Claude should handle "show me unusual options activity" — what columns to show, what threshold to use for "unusual," how to sort the results.

## Common Gotchas

- **"/query-market is not recognized"** — Make sure you're in the project directory and Claude Code can see the `skills/` folder. Run `ls skills/` to verify.
- **"Claude ignores the skill and just responds from training"** — This can happen with older versions of Claude Code. Update to the latest version. Also try rephrasing: start with `/query-market` followed by your specific question.
- **"Claude calls the wrong tool"** — This means the skill's tool selection guidance needs to be more explicit. Edit `skills/query-market.md` to add clearer instructions for the ambiguous query type.
- **"The vol surface output is disorganized"** — The skill includes formatting instructions for volatility surfaces (strikes as rows, expirations as columns). If Claude isn't following them, the question phrasing might be triggering a different code path in the skill.
