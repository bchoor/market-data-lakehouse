You upgrade when: (1) you're trading real size and need precise greeks for position sizing, (2) you want multi-year backtesting of options strategies, or (3) you're building something you want to commercialize.

$50/month sounds like a lot until you compare it to: one losing trade you could have avoided with better data, Bloomberg at $2,000/month, or any options analytics SaaS at $200–$500/month.

### What Alpha Vantage Provides (~3 min)
| Feature | Alpaca Free | Alpha Vantage Premium |
|---|---|---|
| Historical options chains | No (current-day only) | Yes (5+ years) |
| Options pricing | Bid/ask/last | Bid/ask/last + NBBO |
| Greeks | No (computed locally) | Pre-computed by AV |
| Implied volatility | From market prices | AV-computed, cleaner |
| Data latency | 15-min delayed | 15-min delayed |
| Rate limits | 200 req/min | 75 req/min (Premium) |
| Underlyings covered | US equities | US equities + ETFs + indices |

The key difference for most traders is historical chains + pre-computed Greeks. Instead of reconstructing Greeks from bid/ask using Black-Scholes (our approach in EP 4), you get exchange-reported Greeks. For liquid underlyings like SPY, the difference is small. For less liquid names, exchange-reported Greeks are more reliable.

## Key Concepts

**Why $50/mo options data is still cheap**
Professional options traders pay $200–$2,000/month for data depending on the provider (Bloomberg, FactSet, ORATS, OptionMetrics). Alpha Vantage at $50 is the entry point to production-grade historical options data. The key question isn't "is $50 cheap?" but "what's the cost of a bad trade made on imprecise greeks or missing history?" For a trader managing $50k+, one avoided 1% mistake is worth a year of data fees.

**Exchange-reported Greeks vs Black-Scholes approximation**
Our EP 4 approach computes Greeks using Black-Scholes with implied volatility backed out of the option's market price. This works well for liquid options. Alpha Vantage reports Greeks as computed by the exchange (CBOE for most equity options), which accounts for early exercise premiums (for American-style options), dividends more precisely, and uses a volatility smile rather than a flat IV surface. The differences are small for SPY but material for individual stocks near earnings or dividend dates.

**Schema compatibility — drop-in replacement**
The `alpha_vantage_pipeline.py` output is deliberately schema-compatible with the Alpaca + py_vollib output from EP 3–4. Same column names, same types, same partition spec. This means the Iceberg writer, the SQL client, and the MCP server all work identically regardless of which data source you used. You can mix data sources (Alpaca for recent, AV for historical) in the same Iceberg table.

**Other premium data sources to know about**
When you outgrow even this setup:
- **ORATS** (~$200/mo) — best-in-class options data, used by institutional desks
- **OptionMetrics** — academic-grade, used by quant researchers
- **Polygon.io** (~$199/mo) — good for tick-level and real-time data
- **Unusual Whales** — options flow and dark pool data specifically
These all have REST APIs and could be integrated using the same pattern as Alpha Vantage.

## Common Gotchas

- **"Rate limit errors during backfill"** — Alpha Vantage Premium allows 75 requests/minute. The script respects this with built-in throttling. Don't try to parallelize without adjusting the rate limit — you'll get 429 errors and your key may be temporarily suspended.
- **"Historical data starts later than 2020"** — Alpha Vantage's options history depth varies by underlying. SPY goes back to 2020+; smaller names may have shorter history. Check `--test` output for your specific tickers.
- **"The script crashes halfway through a large backfill"** — Use `--resume`. The pipeline saves a checkpoint after each date processed. Resume starts from where it left off.
- **"Alpha Vantage Greeks don't match my broker's Greeks"** — Brokers also compute or source their Greeks differently. Differences of 0.01–0.02 in delta are normal. What matters is consistency within your own dataset, not agreement with any external source.
